# 프로토타입 검증 파이프라인 이식 보고 (화수)

prototype에서 구현·실검증을 마친 파이프라인을 팀장님 TS판(현 main)으로 이식한 작업의 요약입니다.
배경과 합의 근거는 로컬 문서 `보완계획_BranchPort베이스_화수.md`(2026-08-03 공유)를 따릅니다.

## 이식된 기능

| # | 기능 | 내용 |
|---|---|---|
| 1 | 구조화 출력 | `claude -p --json-schema`로 압축·라벨 응답을 JSON으로 강제. 정규식 파싱은 안전망으로 강등 |
| 2 | LLM 턴 제목·요약 | `/api/label` 배치(40턴/회) + `labels/<프로젝트>.json` 해시 캐시. 노드 라벨·카드 제목·요약 한 줄·툴팁에 반영. 프롬프트 절단 headline은 폴백으로만 사용. 15분 이내 최신 턴은 제외하고, 해시에 endTimestamp가 들어가 턴이 완결되면 자동 재라벨 |
| 3 | 압축 상태층 | 압축 시 원본 JSONL을 **세션별 시간창**으로 재스캔해 파일별 실제 diff(+n/−n, 샘플)와 에러 내용 스니펫을 패키지에 동봉. 시크릿 마스킹 포함. LLM을 거치지 않는 결정론 층 |
| 4 | 목적 조건부 압축 | 압축 바에 "받는 쪽 목적" 셀렉트(이어서 구현/버그 수정/팀원 설명) → 요약 프롬프트에 우선순위 지시 |
| 5 | /expand 원문 인출 | `/api/expand?project=&turn=`으로 턴 원문 반환. 압축 패키지에 curl 안내 동봉(패키지 수신자가 부족한 부분을 펼쳐볼 수 있음) |
| 6 | 갈래(브랜치) 대화 | 노드/압축 패키지에서 곁가지 대화. 맥락 = 조상 경로의 제목·요약 + 해당 턴 원문 — "분기 지점 이후는 모르는" AI와 대화. `branches/<프로젝트>.json` 영속, 카드 내 칩+채팅 UI, 노드 ⑂n 배지, 오귀속 방지·낙관 롤백 |
| 7 | 자동 갱신 | `/api/mtime` 10초 폴링. 턴 내용이 실제로 바뀐 경우에만, 애니메이션·카메라 이동 없이 제자리 갱신. 카드·모달·범위 선택 중엔 보류 |

## 함께 들어간 교정

- **팔레트**: 기존 청록/녹색 국면색이 색각 검증 FAIL(실행↔탐색 ΔE 7.4, 기준 15) → 검증 통과 3색
  (실행 `#2a78d6/#3987e5` · 편집 `#eb6834/#d95926` · 탐색 `#1baf7a/#199e70`)으로 교체. 톤 취향이
  갈리면 새 톤으로 재검증 후 되돌릴 수 있습니다(검증 방법은 화수가 보유).
- **스플래시 복구**: 서버 연결 실패 시 스플래시가 화면을 영원히 덮던 문제 → 오류 안내를 띄우고 걷도록 수정.

## 검증 (전부 실데이터·claude 실호출 E2E)

- 라벨: 테스트 프로젝트 118턴 전부 자동 배치 라벨링 완료, 캐시 재사용 확인
- 갈래 대화: 이전 흐름·분기 턴 원문을 정확히 요약하고 **"이 시점 이후는 정보가 없다"고 정확히 답변**
- 압축: 상태층에 실제 파일 diff·에러 스니펫 동봉 확인, `--json-schema` 순수 JSON 응답 확인
- 빌드(tsc)·UI 스크립트 문법 검사 통과, 트리·프로젝트 API 정상 응답

## 참고 사항

- LLM 기능은 로컬 `claude` CLI(`-p` 헤드리스 모드)를 서브프로세스로 실행합니다. 토큰을 직접
  다루지 않으며, CLI가 없으면 해당 기능만 비활성화되고 트리 시각화는 정상 동작합니다.
- CDN 폰트(Pretendard)는 의존성 0 방침과 상충하나 팀 논의 항목으로 남겨두고 건드리지 않았습니다.
- 다음 후보(계획 §4): 갈래 응답의 `[턴 N 원문 필요]` 마커 자동 인출 루프, 갈래 결론의 본선 앵커 노트.
