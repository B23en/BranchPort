# BranchPort 과거 세션 인출

같은 컴퓨터의 BranchPort 서버(포트 4300)가 이 프로젝트의 전체 세션 로그를 인덱싱하고 있다.
아래 절차로 과거 턴을 검색하고 원문을 인출해, **추측 대신 원문 근거로** 답하라.

## 절차

1. **프로젝트명 조회** — 디렉토리명 규칙을 손으로 변환하지 말고(한글 경로는 하이픈이 뭉개져
   실패하기 쉽다) 서버에서 조회하라:
   ```
   curl -s 'http://127.0.0.1:4300/api/projects'
   ```
   현재 작업 경로와 `displayPath`가 일치하는 항목의 `dirName`을 쓴다. 정확히 일치하는 게
   없으면 **현재 경로를 포함하는 가장 긴 `displayPath`**를 고른다 (하위 폴더에서 실행해도
   상위 프로젝트의 기록이 정답인 경우가 많다).

2. **검색**:
   ```
   curl -s 'http://127.0.0.1:4300/api/search?project=<dirName>&q=<키워드>&n=8'
   ```
   - 키워드는 **파일명·함수명·에러명 같은 식별자를 최우선**으로. 개념어는 라벨(제목·요약)에
     있으면 강하게, 원문 앞부분(질문 2,000자·응답 800자)에 있으면 약하게 잡히고, 그 밖이면 못 잡는다.
   - 응답의 `indexed`가 0이면 키워드 문제가 아니라 **프로젝트명이 틀린 것**이다 — 1단계로 돌아가라.
   - `score`가 전반적으로 낮으면(≲10) 매치가 약한 것이다 — **다른 표현으로 2~3회 재시도하라**:
     동의어, 영문 식별자, 관련 파일명 (예: "팔레트" → "색상", "palette", "index.html").
   - `via:"graph"`인 결과는 키워드 매치 없이 파일·식별자 연결로 회수된 턴이다 — 직접 매치가
     빈약할 때 이쪽이 정답인 경우가 많다.

3. **원문 인출** — 유망한 턴의 id로:
   ```
   curl -s 'http://127.0.0.1:4300/api/expand?project=<프로젝트dir명>&turn=<턴id>'
   ```
   질문 원문, 응답, 도구 내역, 만진 파일, 코드 diff(`diffs`)가 나온다.

4. **답변** — 인출한 원문을 근거로 답하되, 어느 시점(턴 시각)의 정보인지 밝혀라.
   원문에 없는 내용은 추측하지 말고 없다고 말하라.

## 서버가 안 떠 있으면 (연결 거부)

```
cd <BranchPort 레포 경로> && npx tsc -p . && node dist/server.js &
```
기동 후 1~2초 뒤 재시도. 레포 위치를 모르면 사용자에게 물어라.

## 한계 (그대로 전달할 것)

- 검색은 이 컴퓨터의 `~/.claude/projects/` 로그만 대상 — 다른 기기 세션은 없다.
- 방금 끝난 턴(5분 이내)은 아직 제목이 생성되지 않았을 수 있다.
